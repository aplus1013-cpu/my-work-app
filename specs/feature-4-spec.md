# Feature 4 명세: 매니저코칭용페이지 생성

작성일: 2026-07-23
근거 문서: [기획서.md](./기획서.md) 24단계, [매출요약앱_흐름도.md](./매출요약앱_흐름도.md) 출력 ②

---

## 무엇을 하는 기능인가
Feature 2(feature2_manager_view.py)가 구성한 매니저별 코칭용 데이터를 받아, 매니저 한 명당 엑셀 코칭 파일 하나씩을 만드는 기능. "계산 결과를 파일로 남긴다"까지만 다루고, 승인·배포는 다루지 않는다.

⚠️ 기획서 24단계의 최종 형태는 "웹페이지(URL 링크)"이지만, 지금 구현은 연습 단계 간소화로 **엑셀 파일**로 대체했다 ([feature-3-spec.md](./feature-3-spec.md)와 동일한 이유).

---

## 입력
- Feature 2의 `manager_views` 데이터(`build_manager_views()`의 결과): 매니저이름 -> 관련 그룹별 목록[채널·품목군조합, 순위목록[순위, 행사자이름, 소속매니저, 거래처명, 누적매출, 달성률, 일평균매출, 내소속 여부]]
- 기획서 24단계 출력 예시 표의 "달성률" 컬럼은 `feature1_engine.attach_achievement_rate()`가 그룹 순위 행마다 해당 행사자의 달성률을 붙여주도록 이미 확장되어 있어, 별도 작업 없이 그대로 쓸 수 있다.

---

## 동작 (순서)
1. `feature1_engine.compute_all()` → `feature2_manager_view.build_manager_views()`를 호출해 `manager_views`를 가져온다
2. `manager_views`에 담긴 매니저를 한 명씩 순회한다
3. 매니저와 관련된 그룹별 전국 전체 순위표를, 기획서 출력 예시 형식(그룹별 표 + 내 소속 표시)에 맞춰 엑셀 시트로 채운다
4. 매니저 이름을 포함한 파일명으로 `outputs/manager-pages/` 폴더에 엑셀 파일로 저장한다
5. 몇 명분의 파일을 생성했는지 콘솔에 요약해서 알려준다

---

## 출력
- `outputs/manager-pages/{매니저이름}.xlsx` — 매니저당 1개 파일
  - 시트에 그룹(채널·품목군 조합)별 표를 순서대로 배치 — 각 표: 전국순위 / 행사자이름 / 소속매니저 / 거래처 / 채널·품목군 조합 / 누적매출(통화 서식) / 달성률(퍼센트 서식) / 내 소속 여부, 전국 전체 순위 정렬, 거래처별로 행 분리
  - 내 소속 행은 배경색으로 강조 표시
- 콘솔: 생성한 파일 수와 저장 경로 요약

---

## 지금은 뺄 것
- 실제 URL 배포·호스팅 / 실제 웹페이지 (엑셀 파일 생성까지만 — 접속 가능한 링크가 아님)
- 담당자 승인 절차
- 카카오톡 자동 발송
- 결과 데이터의 별도 저장(DB 등 영속화) — 생성된 엑셀 파일 자체가 산출물
- 디자인·꾸미기 요소(브랜딩, 이미지, 고급 스타일링) — 굵은 글씨·강조 배경색·통화/퍼센트 서식 등 최소한의 가독성만 다룸
