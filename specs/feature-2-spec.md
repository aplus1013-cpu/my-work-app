# Feature 2 명세: 매니저별 코칭용 데이터 구성

작성일: 2026-07-23
근거 문서: [기획서.md](./기획서.md) 21~23단계

---

## 무엇을 하는 기능인가
매니저가 자기 소속 행사자와 관련된 (채널·품목군 조합) 그룹의 **전국 순위 전체**를 보고, 그 안에서 자기 소속 행사자의 위치를 바로 짚어낼 수 있는 매니저코칭용 데이터를 만드는 로직.

---

## 입력
- Feature 1 엔진(feature1_engine.py)이 계산한 행사자별 결과 데이터: 행사자이름 / 매니저 / 누적매출 / 달성률 / 거래처별 목록(거래처명 / 채널·품목군 조합 / 전국순위 / 그룹인원수 / 근무일수 / 일평균매출)
  - (원본 엑셀의 "매니저" 컬럼값이 행사자당 하나로 고정되어 반복 기재된다고 가정. Feature 1 결과에 이미 매니저 필드가 포함되어 있음 — 별도 매핑 작업 불필요)
- ⚠️ (채널, 품목군 조합) 그룹별 **전국 전체 순위 목록** (그 그룹에 속한 모든 행사자 — 다른 매니저 소속 포함 — 를 순위순으로 나열한 목록)
  - 현재 feature1_engine.py의 `compute_store_rankings()`는 그룹별 전체 순위표를 내부적으로 계산만 해두고, 각 행사자·거래처 항목에 "내 순위/그룹 인원수" 숫자만 담아 반환한다. 이 기능을 만들려면 그룹별 전체 순위 목록 자체(그룹에 속한 모든 행사자이름·거래처명·매니저·누적매출·일평균매출·순위)를 Feature 1 결과에서 함께 꺼낼 수 있도록 먼저 확장해야 한다.

---

## 동작 (순서)
1. 매니저 이름 기준으로 소속 행사자 목록을 그룹핑한다
2. 소속 행사자들이 (거래처 방문 이력을 통해) 걸쳐 있는 (채널, 품목군 조합) 그룹들을 모두 찾는다 (한 매니저의 소속 행사자가 여러 그룹에 걸쳐 있을 수 있음)
3. 각 그룹에 대해, 그 그룹의 전국 전체 순위 목록(다른 매니저 소속 행사자 포함)을 그대로 가져온다
4. 그 전국 순위 목록의 각 행에 "이 매니저 소속인지" 표시를 붙인다 (행사자의 매니저명이 이 매니저와 같으면 표시)
5. 매니저별로, 자신이 속한 그룹들의 "전국 순위 전체 목록(내 소속 표시 포함)"을 묶어 코칭용 데이터로 구성한다

---

## 출력
- 매니저별 데이터: 매니저 이름 + 관련 그룹별 전국 순위 전체 리스트
  - 그룹마다: 채널·품목군 조합 라벨
  - 그룹의 각 행(전국 전체, 순위순): 전국순위 / 행사자이름 / 소속매니저 / 거래처명 / 누적매출 / 일평균매출 / **내 소속 여부**(이 매니저와 같은 매니저인지)
  - "내 소속 여부"로, 매니저가 전체 순위 안에서 자기 팀원이 몇 위인지 스크롤 없이 바로 찾을 수 있어야 함

(웹페이지가 아닌, 다음 단계가 바로 쓸 수 있는 정렬된 계산 결과 데이터 형태로 출력)
