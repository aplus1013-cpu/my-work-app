# Feature 1 명세: 행사자별 매출 요약 계산 엔진

작성일: 2026-07-23
근거 문서: [기획서.md](./기획서.md) 2~17단계

---

## 무엇을 하는 기능인가
채널별 매출 엑셀 파일들을 받아 검증·정제한 뒤, 행사자별 누적매출·목표대비 달성률과 거래처별 전국순위를 계산하는 핵심 로직.

---

## 입력
- 매출 데이터 엑셀 파일 여러 개 (채널별로 파일이 나뉨, 파일 하나당 채널 하나)
- 필수 컬럼 26개 포함: 매니저, 영업담당, 등급, 거래처번호, 거래처명, 2차점ID, 2차점명, 행사자사번, 행사자이름, 고용형태, 직무, 마감일, 목표, 총판매금액, 달성률, DayRate, LineCount, 품목군1~3, 판매수량1~3, 판매금액1~3 (채널은 컬럼이 아니라 파일명에서 파싱, 본부는 사용 안 함)
- ⚠️ 전국순위는 "이번 업로드 파일 전체"가 모수입니다. 같은 채널을 다루는 팀 파일이 여러 개인데 그중 일부만 업로드되면 순위가 틀어지므로, 담당자는 해당 채널의 팀 파일을 빠짐없이 함께 업로드해야 합니다 (이 엔진은 파일이 다 모였는지 자체 검증하지 않음 — 업로드 전 확인은 담당자 책임).

---

## 동작 (순서)
1. 파일 형식 검증
2. 26개 필수 컬럼 존재 여부 검증
3. 엑셀 데이터를 표 형태로 파싱
4. 결측치 제거
5. 이상값 제거 (음수 매출 / 총판매금액-분해금액 불일치 / 그룹 평균 대비 5배 이상 급증 / 중복 입력 행)
6. 거래처별 매출 데이터를 행사자 단위로 매핑
7. 행사자별 마감일 기준 총판매금액을 월초부터 누적 합산
8. 월초부터 최신 마감일까지 누적일수 계산
9. 목표치를 누적일수 비율로 환산 (목표 × 누적일수 ÷ 해당월 전체일수)
10. 행사자별 목표대비 달성률 계산 (누적 매출합계 ÷ 환산 목표치)
11. 각 매출 건의 채널·품목군 조합을 그룹 키로 구성 (품목군 값의 순서는 무관 — 들어있는 값의 집합만 같으면 같은 그룹)
12. 같은 채널 내 품목군 조합이 정확히 일치하는 행사자끼리 그룹핑
13. 그룹별로 근무일수 대비 일평균매출(총판매금액 ÷ 근무일수) 기준 순위 산정 (행사 진행 일수가 사람마다 달라, 누적 총액 그대로 매기면 일수가 많은 사람이 유리해지는 문제를 피하기 위함)
14. 행사자별 달성률(1개)과 거래처·품목군 조합별 전국순위(거래처 수만큼)를 매칭
15. 모든 매출 행이 결측치·이상값으로 제거되어 최종 결과에 남지 않는 행사자는, 제외 사유와 함께 별도로 표시

---

## 출력
- 행사자별 데이터: 이름 / 이번 달 누적 매출 / 누적일수 환산 목표대비 달성률
- 거래처별 데이터 (행사자당 여러 건 가능): 거래처명 / 채널·품목군 조합(품목군 번호 라벨 포함, 예: "가전+생활가전(품목군1,2)") / 근무일수 / 일평균매출 / 그룹 내 전국순위 / 그룹 인원수
  - 그룹 인원수 = 같은 그룹(채널+품목군 조합)에 속한 **서로 다른 행사자 수**. 한 행사자가 같은 그룹에 거래처 여러 곳으로 들어가 있어도 중복으로 세지 않고 한 명으로 센다 (단, 순위는 거래처 단위이므로 그 행사자가 그룹 내에서 여러 순위를 가질 수 있다).
- 완전히 제외된 행사자: 모든 매출 행이 결측치·이상값으로 제거되어 위 목록에 나타나지 않는 행사자를, 이름·사번과 제외 사유(어떤 행이 왜 제거됐는지)와 함께 별도로 표시

(웹페이지가 아닌, 다음 단계가 바로 쓸 수 있는 계산 결과 데이터 형태로 출력)
