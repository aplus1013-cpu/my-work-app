# Feature 3 명세: 행사자별 요약페이지 생성

작성일: 2026-07-23
근거 문서: [기획서.md](./기획서.md) 18단계, [매출요약앱_흐름도.md](./매출요약앱_흐름도.md) 출력 ①

---

## 무엇을 하는 기능인가
Feature 1(feature1_engine.py)이 계산한 행사자별 결과를 받아, 행사자 한 명당 엑셀 요약 파일 하나씩을 만드는 기능. "계산 결과를 파일로 남긴다"까지만 다루고, 승인·배포는 다루지 않는다.

⚠️ 기획서 18단계의 최종 형태는 "웹페이지(URL 링크)"이지만, 지금 구현은 연습 단계 간소화로 **엑셀 파일**로 대체했다 (담당자가 바로 열어보고 다른 곳에 붙여넣기 쉬운 형태가 더 실용적이라는 판단).

---

## 입력
- Feature 1 엔진의 `report` 데이터(`feature1_engine.compute_all()`의 `report` 항목): 행사자이름 / 행사자사번 / 매니저 / 누적매출 / 달성률 / 거래처목록(거래처명·채널·품목군조합·순위·그룹인원수·근무일수·일평균매출)
- 별도 외부 입력 없음 — Feature 1 결과를 그대로 사용

---

## 동작 (순서)
1. `feature1_engine.compute_all()`을 호출해 `report`를 가져온다
2. `report`에 담긴 행사자를 한 명씩 순회한다
3. 각 행사자의 누적매출·목표대비 달성률·거래처별 채널·품목군 조합·전국순위를, 기획서 출력 예시 형식(요약문 + 숫자 강조 + 거래처별 목록)에 맞춰 엑셀 시트로 채운다
4. 행사자사번을 포함한 파일명으로 `outputs/employee-pages/` 폴더에 엑셀 파일로 저장한다
5. 몇 명분의 파일을 생성했는지 콘솔에 요약해서 알려준다 (기존 두 기능의 "[처리 요약]" 톤과 동일하게)

---

## 출력
- `outputs/employee-pages/{행사자사번}_{행사자이름}.xlsx` — 행사자당 1개 파일
  - 시트 상단: 행사자이름 / 이번 달 누적 매출 / 누적일수 환산 목표대비 달성률(사람당 1개, 퍼센트 서식)
  - 시트 표: 거래처별 소속 채널·품목군 조합과 전국순위(거래처마다 각각 한 행) — 거래처 / 채널 / 품목군 조합 / 전국순위 / 그룹인원수 / 근무일수 / 일평균매출 / 누적매출 (금액은 통화 서식)
- 콘솔: 생성한 파일 수와 저장 경로 요약

---

## 지금은 뺄 것
- 실제 URL 배포·호스팅 / 실제 웹페이지 (엑셀 파일 생성까지만 — 접속 가능한 링크가 아님)
- 담당자 승인 절차
- 카카오톡 자동 발송
- 결과 데이터의 별도 저장(DB 등 영속화) — 생성된 엑셀 파일 자체가 산출물
- 디자인·꾸미기 요소(브랜딩, 이미지, 고급 스타일링) — 굵은 글씨·통화/퍼센트 서식 등 최소한의 가독성만 다룸
