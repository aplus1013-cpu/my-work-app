# 기획서: 판촉사원 매출 요약페이지 생성 도구

작성일: 2026-07-22
근거 문서: [매출요약앱_흐름도.md](./매출요약앱_흐름도.md)

---

## 목표
매주 판촉사원(행사자)의 거래처별 매출 데이터를 받아 핵심을 요약하고, 행사자별 요약페이지와 매니저코칭용페이지로 배포하는 도구.

---

## 입력
**매출 데이터 엑셀 파일 여러 개** (채널별로 파일이 나뉘어 있음, 업로드 형태로 받음)
파일명 예: "[영업2팀] 7월 KAT 1026주차 유인행사매출 (~7/15) 공유(件)", "[영업3팀] 7월 NH 1026주차 유인행사매출 (~7/15) 공유(件)" — 파일 하나당 채널 하나

실행 트리거: **매주 화요일**, 담당자가 채널별 엑셀 파일들을 업로드하면 처리 시작 (화요일에 못 받으면, 늦게라도 파일이 올라오는 시점에 처리 시작)

⚠️ **전국순위는 "이번에 업로드된 파일 전체"를 기준으로 계산됩니다.** 시스템은 실제로 받은 데이터만 알 수 있으므로, 같은 채널을 다루는 팀 파일이 여러 개인데 그중 일부만 업로드되면 그 채널의 순위 모수가 줄어들어 실제 전국 순위와 다르게 계산됩니다. 담당자는 업로드 전에 **해당 채널을 다루는 모든 팀의 파일이 다 모였는지 확인한 뒤 한 번에 업로드**해야 합니다.

포함 컬럼 (총 26개, 채널은 컬럼이 아니라 파일명에서 파싱 — 아래 참고):

1. 매니저
2. 영업담당
3. 등급
4. 거래처번호
5. 거래처명
6. 2차점ID
7. 2차점명
8. 행사자사번
9. 행사자이름
10. 고용형태
11. 직무
12. 마감일(행사진행 날짜)
13. 목표
14. 총판매금액
15. 달성률(해당 일자·1일 기준)
16. DayRate(사용 안 함)
17. LineCount(사용 안 함)
18. 품목군1
19. 품목군2
20. 품목군3
21. 판매수량1
22. 판매수량2
23. 판매수량3
24. 판매금액1
25. 판매금액2
26. 판매금액3

⚠️ "채널"과 "본부"는 데이터 컬럼이 아닙니다. 채널은 파일명에서 파싱하고(12단계 참고), 본부는 앱에서 쓰지 않습니다. 대신 2차점ID/2차점명이 실제 컬럼입니다.

---

## 단계

1. 매주 화요일, 담당자가 채널별 매출 데이터 엑셀 파일들을 업로드하면 처리 시작 (화요일에 못 받으면, 늦게라도 파일이 올라오는 시점에 처리 시작)
2. 파일 형식 검증
3. 입력에 정의된 26개 필수 컬럼 존재 여부 검증
4. 엑셀 데이터를 표 형태로 파싱해서 불러오기
5. 결측치 제거 (데이터 정제)
6. 이상값 제거 — 아래 4가지 중 하나라도 해당하면 이상값으로 제외
   - 음수 매출: 판매금액1/2/3 중 하나라도 마이너스
   - 금액 불일치: 총판매금액 ≠ 판매금액1+판매금액2+판매금액3
   - 비정상적 급증: 같은 채널·품목군 조합 그룹 평균 대비 5배 이상 (오탈자·중복 입력처럼 명백한 입력 오류만 걸러내기 위한 보수적인 시작값 — 정상적인 실적 편차까지 잘라내지 않도록 넉넉하게 잡았다. 실제 데이터로 오탐/누락 사례를 보며 조정 가능)
   - 중복 입력: 거래처번호+행사자사번+마감일+품목군이 동일한 행이 2건 이상 (첫 건만 남기고 나머지 제외)
7. 거래처별 매출 데이터를 행사자 단위로 매핑
8. 행사자별로 마감일(행사진행 날짜) 기준 총판매금액을 월초부터 누적 합산
9. 해당 월의 누적일수 계산 (월초부터 최신 마감일까지 달력상 경과일수)
10. 월 목표치를 누적일수 비율로 환산 (목표 × 누적일수 ÷ 해당월 전체일수(달력상 일수))
11. 행사자별 목표대비 달성률 계산 (누적 매출합계 ÷ 누적일수 환산 목표치)
12. 각 매출 건의 채널 / 품목군 조합(값이 있는 품목군 전체, 1~3개)을 그룹 키로 구성 (채널은 파일이 이미 채널별로 나뉘어 있어 자동으로 구분됨, 등급은 그룹 키에 넣지 않음)
13. 같은 채널(파일) 내에서, 품목군 조합이 정확히 일치하는 행사자들끼리 그룹핑 (품목군 개수와 값이 모두 같아야 같은 그룹 — 예: 품목군이 2개면 2개가 다 같은 사람끼리만 비교. 입력 순서는 무관 — 품목군1/2/3 중 어느 칸에 어떤 순서로 들어있든 값의 집합만 같으면 같은 그룹)
14. 그룹별로 전국 행사자 근무일수 대비 일평균매출(총판매금액 ÷ 근무일수) 기준 순위 산정 (행사 진행 일수가 사람마다 달라, 누적 총액 그대로 매기면 일수가 많은 사람이 단지 그 이유만으로 유리해지는 문제를 피하기 위함)
15. 행사자별로 본인의 목표대비 달성률 값 매칭 (사람당 1개)
16. 매출 건(거래처·품목군 조합)별로 전국순위 값 매칭 (한 행사자가 여러 거래처를 다녔으면 거래처 수만큼 여러 개)
17. 행사자별로, 소속된 거래처·품목군 조합별 순위 항목을 모두 모아 요약페이지 형식에 맞게 구성
18. 행사자별 요약페이지 생성
19. 담당자가 행사자별 요약페이지 내용을 확인하고 승인
20. 승인 완료 시, 행사자별 요약 엑셀 파일을 다운로드할 수 있도록 제공
21. 매니저 컬럼 기준으로 소속 행사자 목록 그룹핑
22. 소속 행사자들이 걸쳐 있는 "채널·품목군 조합" 그룹을 모두 찾아, 각 그룹의 전국 전체 순위 목록(다른 매니저 소속 행사자 포함, 그 그룹에 속한 모두)을 상위권 → 하위권 순으로 그대로 가져옴 (한 행사자가 여러 거래처를 다녔으면 거래처별로 행을 나눠서 표시)
23. 매니저별 코칭용 데이터 구성 — 위 전국 전체 순위 목록에 "내 소속 행사자(같은 매니저)" 여부를 표시해서, 매니저가 전체 순위 안에서 자기 팀원의 위치를 바로 찾을 수 있게 함
24. 매니저코칭용페이지 생성
25. 담당자가 매니저코칭용페이지 내용을 확인하고 승인
26. 승인 완료 시, 매니저별 코칭용 엑셀 파일을 다운로드할 수 있도록 제공

---

## 출력

### ① 행사자별 요약페이지 — 엑셀 파일 (담당자 승인 후 다운로드 제공), 형식: 요약문 + 숫자 강조 + 거래처별 목록
포함 항목: 행사자이름 / 이번 달 누적 매출 / 누적일수 환산 목표대비 달성률(사람당 1개) / 거래처별 소속 채널·품목군 조합과 전국순위(거래처마다 각각 표시)

**예시**
> 홍길동 님, 이번 달 누적 매출 **3,200만원** (누적일수 기준 목표 대비 **106% 달성**).
> - ○○마트: B채널 · 가전(품목군1) 그룹 전국 350명 중 **45위**
> - ○○백화점: B채널 · 가전+생활가전(품목군1,2) 그룹 전국 127명 중 **12위**

### ② 매니저코칭용페이지 — 엑셀 파일 (담당자 승인 후 다운로드 제공), 형식: 그룹(채널·품목군 조합)별 표 (전국 전체 순위 정렬, 거래처별로 행을 나눠서 표시)
포함 항목: 전국순위 / 행사자이름 / 소속매니저 / 거래처 / 채널·품목군 조합 / 누적매출 / 달성률 / **내 소속 여부**(로그인한 매니저와 같은 매니저인지)

이 표는 매니저 자기 소속 행사자만 뽑은 목록이 아니라, 소속 행사자가 걸쳐 있는 그룹의 **전국 전체 순위**를 그대로 보여준다. 다른 매니저 소속 행사자도 함께 나오고, 그중 자기 소속 행에만 표시가 붙어 전체 순위 속 내 팀원의 위치를 바로 확인할 수 있다.

**예시** (홍길동·김철수가 속한 "B채널·가전+생활가전" 그룹, 홍길동의 매니저 관점)
| 전국순위 | 행사자이름 | 소속매니저 | 거래처 | 채널·품목군 조합 | 누적매출 | 달성률 | 내 소속 |
|---|---|---|---|---|---|---|---|
| 12위 | 홍길동 | 김민준 | ○○백화점 | B채널·가전+생활가전 | 3,200만원 | 106% | ✅ |
| 34위 | 김철수 | 정하윤 | △△마트 | B채널·가전+생활가전 | 2,900만원 | 98% | |
| 45위 | 이영희 | 김민준 | ○○마트 | B채널·가전+생활가전 | 2,500만원 | 90% | ✅ |
| … | … | … | … | … | … | … | … |
| 127위 | 박민수 | 류시우 | □□슈퍼 | B채널·가전+생활가전 | 1,100만원 | 52% | |

(※ 예시 수치는 형식 설명용 가상의 값이며, 실제 데이터가 아닙니다. 같은 행사자라도 거래처마다 행이 따로 있고, 누적매출·달성률은 사람 기준 값이라 같은 행사자의 행끼리는 동일합니다. 그룹은 채널·품목군 조합별로 나뉘며, 매니저는 자기 소속 행사자가 걸쳐 있는 그룹들만 확인합니다.)

## 참고 사항
아래는 단계·출력 섹션의 규칙을 보충 설명하는 참고용 메모입니다.

- 승인 완료 후 제공되는 것은 카카오톡 자동 발송이 아니라 엑셀 파일 다운로드입니다(20, 26단계). 담당자가 다운로드한 파일을 각 행사자·매니저에게 전달하는 것은 앱 범위 밖입니다.
- 원본 "달성률" 컬럼은 해당 일자(1일) 기준 값이라, 앱이 계산하는 누적일수 환산 달성률(9~11번 단계)과는 다른 값입니다. 화면에는 앱이 계산한 값을 씁니다.
- 원본 "DayRate", "LineCount" 컬럼은 이 앱에서 사용하지 않습니다.
- 그룹핑은 "같은 채널 내에서 품목군 조합 전체가 정확히 일치"해야 같은 그룹입니다 (품목군이 1개면 1개끼리, 2개면 2개가 다 같은 사람끼리, 3개면 3개가 다 같은 사람끼리 비교). 입력 순서는 무관하며, 값의 집합만 같으면 같은 그룹입니다.
- 채널은 파일이 이미 채널별로 나뉘어 올라오므로 별도 매칭 단계 없이 자동으로 구분됩니다. 등급 컬럼은 그룹핑·순위 기준에는 쓰지 않습니다.
- 누적 매출 합산은 "총판매금액" 컬럼을 그대로 씁니다 (판매금액1+2+3을 따로 재계산하지 않음). 다만 그룹 내 순위 산정은 이 총판매금액 원값을 그대로 비교하지 않고, 행사자별 근무일수(해당 거래처에서 뛴 고유 마감일 수)로 나눈 일평균매출로 비교합니다 — 행사 진행 일수가 사람마다 달라, 원값 기준으로는 일수가 많은 사람이 유리해지기 때문입니다.
- 출력 예시의 "전국 OOO명"은 같은 그룹에 속한 서로 다른 행사자 수입니다. 한 행사자가 같은 품목군 조합으로 거래처 여러 곳을 뛰어 같은 그룹에 여러 번 들어가더라도, 인원수는 중복으로 세지 않고 한 명으로 셉니다 (순위는 거래처 단위로 여러 개 가질 수 있습니다).
- 결측치·이상값 제거로 인해 한 행사자의 매출 행이 전부 사라지면, 그 행사자는 결과에서 빠지되 어떤 사유로 제외됐는지 함께 안내합니다.
- "해당월 전체일수"는 달력상 날짜 수(예: 7월이면 31)를 씁니다 (영업일 기준 아님).

---

## 제약
- 실제 사내 자료·개인정보는 넣지 않고, 연습은 가짜 예시 데이터로만 한다.
- 다운로드 제공 전 최종 결과는 반드시 담당자가 한 번 확인·승인한다. 승인 이후 엑셀 파일을 다운로드할 수 있도록 하는 것까지만 시스템이 처리하며, 이후 각 행사자·매니저에게 전달하는 것은 담당자의 몫이다.
- 전국순위는 이번 업로드 파일 전체가 모수이므로, 채널별로 팀 파일이 나뉘어 있다면 해당 채널의 팀 파일을 빠짐없이 함께 업로드해야 한다. 일부만 업로드하면 순위가 틀어지며, 이는 시스템이 자동으로 검증해줄 수 없어 담당자가 업로드 전에 직접 확인해야 하는 부분이다.
